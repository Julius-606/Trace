3. Core Component Specifications
Module 1: XDG Compliance & Storage (config.py)
    • Must implement robust path resolution following the XDG Base Directory Specification:
      
        ◦ Primary data path: ~/.local/share/trace/ (respecting $XDG_DATA_HOME).
          
        ◦ Subdirectories to auto-create on startup: syllabi/, assets/.
          
        ◦ Database file location: ~/.local/share/trace/trace_local.db.
          
Module 2: Database Layer (database.py)
    • Must use Python's built-in sqlite3 module with row factories enabled.
      
    • Schema Requirements:
      
        1. user_wallet: Stores the user's virtual currency (neurons_balance, single-row constraint where id = 1).
           
        2. unlocked_units: Tracks purchased/unlocked course units (unit_id PK, course_id, unlocked_timestamp, neurons_spent).
           
        3. unit_progress: Tracks completion status (unit_id PK, score, status CHECK constraint: LOCKED, UNLOCKED, COMPLETED, last_accessed).
           
Module 3: Repository & Transaction Logic (repository.py)
    • Implements atomic transactions for the Neurons economy:
      
        ◦ Balance checks before unlocking.
          
        ◦ Atomic deduction of Neurons and insertion into unlocked_units and unit_progress.
          
        ◦ Methods: get_wallet_balance(), add_neurons(amount), unlock_unit(unit_id, course_id, cost), is_unit_unlocked(unit_id).
          
Module 4: Desktop User Interface (ui/main_window.py & components)
    • Built with PyQt6 / PySide6.
      
    • Clean, dark-mode friendly styling matching developer-first Linux aesthetics.
      
    • Dashboard panels:
      
        ◦ Sidebar / Navigation: Switch between Dashboard, Syllabi, Assessment Center, and Wallet.
          
        ◦ Syllabus Browser: Renders hierarchical course structures loaded from local JSON files in syllabi/. Units display lock icons based on local SQLite state. Clicking a locked unit prompts the user to spend Neurons.
          
        ◦ Neurons Widget: Real-time badge showing current Neuron balance, with an action button to earn or simulate top-ups.
